ARCHITECTURAL DECISION (Phase 2): systemd-boot + grub-btrfs

Issue: SPEC §1 mandates systemd-boot (primary UEFI). SPEC §12 reuses grub-btrfs
for snapshots. But grub-btrfs only generates GRUB entries, not systemd-boot.

Solution (documented in STATUS.md):
  • BIOS path: grub-btrfs as-is (pure reuse)
  • UEFI path: custom pacman hook (glue code per SPEC §12)
    - Regenerates systemd-boot snapshot entries after every snapper snapshot
    - ~100 lines Bash, fits "glue" definition
    - Future optimization candidate (Phase 9 real-hardware testing)
